4)	Design and implement a Python program that identifies and extracts the registration number printed on a car's number plate from a given input image using image processing techniques, Optical Character Recognition (OCR), and a knowledge-based expert system.
The system should accept an image containing a car and its number plate, locate the number plate region, preprocess the cropped image to improve text visibility, and extract the registration number using an OCR engine. A knowledge base containing the applicable vehicle registration format, character patterns, and validation rules should then be used to verify the extracted text and determine whether it follows the expected registration format.
The system should perform the following tasks:
5)	Input Image: Read a car image from a specified image file in JPG, JPEG, or PNG format.
6)	Number Plate Detection: Identify and crop the number plate region using image processing or a pretrained object detection model.
7)	Image Preprocessing: Convert the cropped plate to grayscale, reduce noise, improve contrast, and apply thresholding to enhance character visibility.
8)	Text Extraction: Use an OCR engine such as Tesseract OCR to extract the registration characters from the number plate.
9)	Knowledge Base Construction: Create a knowledge base containing the applicable registration-number format, expected character patterns, and validation rules.
10)	Rule-Based Validation: Apply expert-system rules to check the extracted text against the expected registration format, allowing for common OCR errors where appropriate.
11)	Result Display: Display the original image, cropped number plate, extracted registration number, and validation result.
12)	Error Handling: If the number plate cannot be detected or the extracted text does not satisfy the validation rules, display a suitable error message and allow the image to be checked again.
